---

## 🌟 Overview
The **AI Training Assistant Frontend** is an interactive learning and coding assessment platform. It equips students and developers with an in-browser code editor, multi-language compilation, real-time code evaluation, and automated feedback powered by AI.

---

## 🚀 Key Features

- 💻 **In-Browser Code IDE**: Multi-language code editor supporting Python, JavaScript, and Java with line numbering and syntax highlighting.
- ⚡ **Live Execution & Automated Tests**: Run code against pre-configured input/output test suites with execution time benchmarks.
- 🤖 **AI Assistant & Hint Generator**: Context-aware AI explanations and hints for syntax errors and edge case failures.
- 📊 **Progress & Quiz Engine**: Interactive assessment modules with multiple-choice questions, difficulty filters, and score tracking.
- 🎨 **Modern Dark UI**: Engineered with React 18 and Tailwind CSS for a distraction-free development environment.
